# Repositório para facilitadores UNIVESP

Por ora, adicionei somente o template para relatório mensais. Adicionarei mais templates (ou outras coisas) conforme o necessário.

## Compilação

Requer **LuaLatex**. Se você for compilar localmente e não sabe como, jogue esse repositório em alguma LLM e ela vai saber te ajudar. No overleaf provavelmente deve compilar sem problemas, mas novamente, caso não compile direito, qualquer LLM consegue te ajudar.
